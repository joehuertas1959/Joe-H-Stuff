# Joe H Bridge — Work / Personal dashboard

A one-page dashboard with two faces, **Work** and **Personal**, styled after the
Bridge OS v2 design (dark Nocturne ground, Barlow Condensed labels, angled
colour nav blocks, framed panels).

## Flipping faces

- Click **Work** / **Personal** at the top of the left rail, or
- press **S** anywhere outside a text box, or
- open the page with `#work` or `#personal` on the end of the address.

Each face has its own instrument colour (Work violet, Personal green), its own
pages and its own saved data. Nothing from one face shows on the other.

## What each face shows

| Face | Page | Source |
|---|---|---|
| Work | Bridge | Alert tiles + priority queue, today's timeline, comms, quick links |
| Work | Tasks | Typed in; sorted by severity, then overdue |
| Work | Timeline | **Live** Outlook calendar (Microsoft 365), Mon–Fri this week |
| Work | Comms | **Live** newest Outlook mail (Microsoft 365) |
| Work | Log & links | Typed in: notes + links |
| Personal | Quarters | Alert tiles + errands, habits, today, goals, Gmail, links |
| Personal | Errands | Typed in |
| Personal | Timeline | Typed-in personal events, Mon–Sun this week |
| Personal | Goals | Habits (7-day dots, streak) and goals (progress %) |
| Personal | Comms | **Live** unread Gmail, Primary inbox |
| Personal | Log & links | Typed in: notes + links |

## Two ways to run it

1. **Hosted on claude.ai** (live data). The page reads Microsoft 365 and Gmail
   through your claude.ai connectors, using your own sign-in. It asks you to allow
   each connector the first time. Typed entries save to your claude.ai account,
   private to you.
2. **Locally**: open `index.html` in a browser. Typed entries save in that
   browser only. Live calendar and mail don't load locally, because the
   connectors only run inside claude.ai.

## Files

- `dashboard.html`: the page source (what gets published to claude.ai).
- `index.html`: a standalone copy for local use, generated by `node build.mjs`.
  Edit `dashboard.html`, then rebuild.
